Validated with Python 3.14.5 locally, Python 3.11 in the ARM64 Docker runtime, and Docker Compose 5.1.2. Beads/beads-mcp 1.3.1, Dolt 2.5.1, and beads-ui 0.12.6 were exercised together. SDK HTTP/concurrency tests use an in-memory transport; the Compose smoke workflow uses synthetic GitHub records and a synthetic SQL password. Credentialed GitHub behavior/performance, AMD64 builds, full browser interactions, and backup/restore remain unverified. No registry push, source-item write-back, or credentialed source sync has been performed.

A local synthetic inventory check used 100 repositories and 20,000 already-closed beads, with database and network I/O replaced by in-memory snapshots. Median traversal time over three runs fell from 0.1624 seconds before repository indexing to 0.0096 seconds afterward. This isolates inventory processing rather than end-to-end sync latency; the operation-count regressions above provide stable CI checks without timing thresholds.
